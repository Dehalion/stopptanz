# Mirror to a public GitHub repo; publish to both F-Droid (official repo) and Google Play at once

The canonical repo is a private self-hosted Forgejo instance (`ssh://git@plutos:222/david/stopptanz.git`), which F-Droid's official repo cannot build against (not internet-reachable, and F-Droid needs a public source tree to review and build reproducibly). Considered making the Forgejo instance itself public, using Codeberg, or mirroring to GitHub; chose a GitHub mirror since the author already has an account there and it's the default expectation for F-Droid submitters and outside contributors — Forgejo stays the working origin. For F-Droid distribution, considered the official F-Droid repo (they build from source and sign, slower review, most trusted/discoverable) versus IzzyOnDroid or a self-hosted repo (faster, self-signed, lower discoverability); chose the official repo despite slower turnaround, since discoverability and trust matter more than release speed for this project. Decided to pursue Google Play in parallel rather than sequencing F-Droid first, accepting the extra upfront cost (Play Console account, signing, store listing, privacy policy) to reach both audiences from the first release. Consequently: `targetSdk` must be bumped from 34 to 35 to meet Play's current new-app submission floor (36 required by 2026-08-31, extension to 2026-11-01 available) — tracked as an immediate follow-up, not deferred. GitHub mirror lives under the author's personal account, "Dehalion" (`github.com/Dehalion/stopptanz`), matching the pseudonym used for copyright attribution ([[0003-gpl-3-license-for-public-release]]).
